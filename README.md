# T3 Code themes

I was looking for a theme for T3 Code (absolutely goated, by the way). I found some good color themes on [T3 Themes](https://t3themes.com/), but I wanted something a bit more animated.

So I made Koi Pond. I absolutely loved having fish swim around my chat and tried making a few more themes after that. I still haven’t made another one I like quite as much.

[Browse the themes](https://t3code-themes.vercel.app/)
