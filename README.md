# T3 Code themes

I was looking for a theme for T3 Code (absolutely goated, by the way). I found a lot of good color themes on [T3 Themes](https://t3themes.com/), but I wanted to see what else the workspace could do. Somewhere in that thought I decided there should be a fish swimming around my chat.

So I made my own. There’s a koi pond, a couple of takes on Minecraft, and a snowy window for when I feel like working through a blizzard.

[Browse and customize the themes](https://t3code-themes.vercel.app/)

## Install a theme

Download the JSON from the gallery or customize it in the live preview first. In T3 Code, open **Settings → Appearance → Import a file**, then select the imported theme.

Made one yourself? [Submit a theme](https://t3code-themes.vercel.app/submit) or follow the [contribution guide](CONTRIBUTING.md) to open a pull request. Minecraft’s workbench theme is by [Hike-12](https://github.com/Hike-12).

## Run locally

```sh
cd next
npm ci
npm run dev
```

See the [contribution guide](CONTRIBUTING.md) for checks and deployment configuration.
