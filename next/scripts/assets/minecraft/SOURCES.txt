Desktop theme runtime
The installed T3 Code theme schema accepts palette roles, CSS, and an optional
background image. The app inserts the CSS into a stylesheet. Theme files
cannot run JavaScript or add DOM, event handlers, or form inputs.
CSS can read the native model picker through its accessible label. A clickable
pseudo-element cannot keep its own selection or change the model. A native
mob picker needs a persisted T3 Code preference and an app-owned control.

Use Match model for automatic selection. To pin a mob, select it in the studio
composer footer, download the JSON, and import it in Settings > Appearance.
The pinned mob still gets its working gear from the active model label.
The model name selects the weapon material. The effort detail in the native
picker's accessible label independently selects the enchantment. An absent
or unrecognized effort detail leaves the weapon unenchanted.
